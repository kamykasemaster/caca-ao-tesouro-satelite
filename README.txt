Arquivos:
index.html
style.css
script.js

ANTES DE PUBLICAR:
1. Abra script.js.
2. Troque EVENT_DATE pela data/hora oficial.
3. Troque REGISTRATION_URL pelo link do formulário.
4. Em index.html, substitua SUA MARCA.
5. Substitua WhatsApp, Instagram e e-mail pelos contatos reais.

GITHUB PAGES:
1. Envie os três arquivos para a raiz do repositório.
2. Faça Commit.
3. Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main / (root).
6. Save.
